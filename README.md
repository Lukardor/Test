# Forza Horizon 6 - HTML Web Prototype

Dies ist jetzt eine **HTML/CSS/JavaScript**-Version als spielbarer Browser-Prototyp.

## Start

Öffne `web/index.html` im Browser.

## Features im Prototyp

- Große Open-World-Karte mit Biomen (Stadt, Dörfer, Autobahnen, Berge, Wüste, Wald, Küste, Rennstrecken)
- Dynamisches Wetter + Tag/Nacht
- Fahrgefühl mit Beschleunigung, Grip-Modifiern und Lenkung
- Dynamische Events und simulierte Multiplayer-Anzeige (bis 100 Spieler)
- HUD, Event-Feed, Menü/Hinweise

## Hinweis

Ein echtes AAA-Spiel mit UE5-Grafik, globalem Multiplayer, lizenzierter Fahrzeugflotte und vollwertiger KI benötigt ein großes Studio-Team. Dieser Stand liefert einen modernen, erweiterbaren Web-Gameplay-Prototypen.
